# Page copy

One file per page. Write the copy here before WordPress is set up; it is loaded into the pages when the site is installed, so nothing is typed twice.

**How to edit (no software needed):** open a file on GitHub, click the pencil icon, replace each `[Write here]`, then click **Commit changes**. Every save is kept in the history.

Rules:
- Keep the section headings. Delete a section only if there is nothing true to say.
- Do not change the URL, H1, keyword or SEO fields without checking with Hayo. If the copy changes the angle, suggest a new SEO title in a comment under the table.
- Plain, warm, specific language. Australian spelling. No outcome promises on health pages.
- Health pages need a named clinician in "Reviewed by". If unknown, leave `[Write here]` and flag it.
- When a page is ready for review, change `Status: DRAFT` to `Status: READY`.

Order: 07 and 08 first (Mums and Bubs and Seniors, the KPI pages), then 01 to 06, then the rest in number order.
